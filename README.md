# Narcotráfico en la frontera norte · Presentación TIF (UADE 2026)

Presentación web estática para la defensa. No necesita instalar nada ni compilar.

## Controles
| Tecla | Acción |
|---|---|
| → / Espacio / clic | Siguiente |
| ← | Anterior |
| F | Pantalla completa |
| N | Notas del orador |
| O / Esc | Índice de diapositivas |
| Inicio / Fin | Primera / última |

Cada diapositiva tiene su URL (`/#7`). En el celular se lee como una página con scroll.
Para exportar a PDF: Imprimir → Guardar como PDF (una diapositiva por página).

## Publicar en Vercel
1. vercel.com → **Add New → Project** → importar el repo `tesis`.
2. Framework preset: **Other**. Sin comando de build. Output directory: raíz.
3. Deploy. Cada push a la rama vuelve a publicar.

## Ver en local
Abrir `index.html` en el navegador, o `npx serve .`
